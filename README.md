# AML Cordova - Frontend Web Portal 🖥️

## Descripción
Interfaz de usuario moderna y reactiva para el sistema de prevención de lavado de activos **AML Cordova**. Esta aplicación permite a los analistas monitorear transacciones, gestionar auditorías y visualizar perfiles de riesgo mediante un panel de control intuitivo y de alto rendimiento.

## ⚡ Tecnologías Principales
* **Framework:** Angular 21 (Standalone Components)
* **Estado y Reactividad:** Signals (Fine-grained reactivity)
* **Estilos:** Tailwind CSS 4.2
* **Iconografía:** Lucide Icons
* **Notificaciones:** Ngx-Sonner
* **Arquitectura:** Layout-based con Nested Routing
